Yggdrasil Forge is built so that **an AI (or any pipeline) can author a complete, playable tree without opening the editor**. What makes it possible isn't magic: everything the editor knows how to do also exists as data and as a command.

## The loop

```
generate → ygg validate → (fix) → ygg layout → ygg render → look → iterate
```

1. **Generate.** Give the model two things: the [published JSON Schema](../../contrato/ficheiro-e-schema/) and one or two documents from the [gallery](../../exemplos/galeria/) as examples. Ask for a tree on any topic — *"a 15-node tree for learning the Galician bagpipes, in Galician and English, with two resources"*.
2. **Validate.** `ygg validate tree.json --json` returns `{ ok, issues[] }`: the errors are **data**, not prose for humans, so the model can fix its own output in a closed loop. It is exactly the same validation the editor runs on import.
3. **Lay out.** `ygg layout tree.json --algo layered`. The model has no reason to invent coordinates; if the trees have nodes with several parents (the norm in curricula), `layered` is the engine to use.
4. **Dress.** Two fields: `"editor": { "theme": { "preset": "neon", … } }` (copying a preset's spec from the gallery) and `"icon": "logic-key"` on the nodes. → [Theming](../../theming/)
5. **Render.** `ygg render tree.json --out tree.svg` — the model can **look at its own result** (vision models read SVG/PNG) and self-critique: crowded nodes, long labels, empty branches.
6. **Import.** Paste the JSON into the editor's **Código** (code) panel → *Validar* → *Aplicar*, and you are now hand-tweaking what the machine proposed.

## A prompt that works

> Generate a valid Yggdrasil Forge document according to this JSON Schema: `[schema]`. Here is an example: `[minimal.json]`. I want a progression tree about **[topic]** with **[N]** nodes, labels in `gl` and `en`, one resource called **[resource]** with enough `initial` to unlock half the tree, chained prerequisites (several nodes with two parents), and icons from the `logic-*`/`norse-*` sets. Do not include `position` on the nodes. Return only the JSON.

Then: `ygg validate` → `ygg layout --algo layered` → `ygg render`.

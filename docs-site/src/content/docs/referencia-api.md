---
title: Sobre a referencia de API
description: Como se xera a referencia de API, e por que vai nunha soa lingua.
---

A sección API xérase **automaticamente do TSDoc do código fonte** en cada build desta documentación (typedoc; o mesmo patrón anti-deriva cá galería: nada escrito á man, nada commiteado — se a xeración falla, o build do site falla). Cobre os paquetes públicos: `common`, `core`, `react`, `editor-core` e `cli`.

**Nota de lingua**: a diferenza do resto do sitio (bilingüe estrito), a referencia xerada vai **nunha soa lingua — a do TSDoc fonte**, maioritariamente galego. Traducir documentación xerada é inmantible: a copia traducida derivaría do código na primeira semana. Preferimos unha referencia sempre exacta a dúas a medias.

**Language note**: unlike the rest of this site (strictly bilingual), the generated API reference comes in **a single language — the language of the source TSDoc**, mostly Galician. Translating generated documentation is unmaintainable: the translated copy would drift from the code within a week. We prefer one always-exact reference over two half-true ones.

Para unha introdución guiada, mellor comeza por [conceptos](../contrato/conceptos/) e [o ficheiro e o schema](../contrato/ficheiro-e-schema/); a referencia é para cando xa sabes o que buscas.
